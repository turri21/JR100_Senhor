|---|---|---|---|---|---|---|
| `JR100Computer`、`JR100Display`、`JR100R6522` | HDL化の対象範囲を実装済みの挙動に固定する | Python実装が割り当てるアドレス空間、文字表示、キーボード選択、VIAによる音声制御 | 状態 | ROMロード後、CPUがメモリマップドI/Oを読書きし、画面と音声を更新する | 参照実装準拠範囲 | |
| `cpu.py`、CPU移植ノート、JR-100技術資料、利用者の確定判断 | CPU置換時に実機仕様と参照実装の優先順位を固定する | MB8861Hの6800互換命令、割込み、WAI、ADX、NIM、OIM、XIM、TMMと各命令のクロック数 | 状態 | リセットまたは割込みの後、命令フェッチ、実行、クロック加算を行う | CPU互換要件 | |
| `debug_runner.py`、ヘッドレスランナー資料 | HDLと参照実装を機械比較できるようにする | 同一ROM・プログラムに対する命令境界のCPU状態、VIA状態、メモリ範囲の記録 | 記録 | ROMとプログラムをロードした後、命令を実行し、比較用に出力する | 命令境界トレース | 命令境界トレースとは、各命令の完了直後に採取するCPU・VIA・メモリ状態の記録を指す。 |
| MiSTer公式開発資料 | MiSTer標準機能へ接続する方式を固定する | `emu`、`CONF_STR`、`hps_io`、OSD選択ファイルの`ioctl_*`入力、標準ゲームディレクトリ | 手段 | コア起動後、OSD設定を読み、選択ファイルをHPSからFPGAへ転送する | MiSTer統合 | |
| JR-100U公式操作説明書 | 国内版の共通ハードウェア仕様を独立に照合する | 32×24表示、16 KiB RAM、8 KiB ROM、CGRAM、VRAM、VIA、600ボーFSKカセット | 記録 | 国内版資料とPython実装を照合した後、共通項を確認し、国内版との差分を分離する | JR-100U照合資料 | |
| JR-100技術資料、`JR-100.pdf`、Python実装、利用者の確定判断 | 実機仕様と参照実装の差を黙って設計へ取り込まない | ADX immediateのサイクル数、CGRAMとVRAMの重なりを使う96文字 | 状態 | HDL詳細設計を確定する前に、一次資料またはプロジェクトの採用判断で解決する | 実機との差分 | |
| Python版の拡張I/O実装、Java版、MiSTer公式`hps_io`資料 | ホストのゲームコントローラ入力をJR-100互換の読み出し値へ一意に変換する | `$CC02`のbit 0–4を右、左、上、下、スイッチのactive-high入力とし、無入力を`0x00`とする値、およびMiSTerの`joystick_0`方向・ボタン入力 | 状態 | `hps_io`がコントローラ状態を更新した後、CPUが`$CC02`を読み出す前に組み合わせる | ジョイスティック入力変換 | ジョイスティック入力変換とは、MiSTerの`joystick_0`状態をJR-100の`$CC02`読出し値へ組み替える処理を指す。 |
| Python版のVIA・音声実装、音声回帰の調査結果 | 出力帯域外の矩形波を可聴域へ折り返さず、VIA内部動作は維持する | Timer 1、PB7、PB6、Timer 2をCPUクロック基準で更新する経路と、その結果をMiSTer音声出力へ渡す直前に出力可否を決める経路 | 状態 | Timer 1の値から内部信号を更新した後、MiSTer音声出力へ渡す前に帯域を判定する | 音声出力帯域制御 | 音声出力帯域制御とは、VIA内部状態を変えずにMiSTer音声出力へ渡す信号だけを出力可能な周波数帯域へ制限する処理を指す。 |
| 利用者の一般化指示、Python版のジョイスティック・音声試験 | 特定のゲームへ依存せず入力と音声の互換性を判定する | 無入力、各方向、同時方向、スイッチ、押下保持、可聴帯域内外の音声、および帯域外でも継続するVIA内部状態を独立に与える試験 | 手段 | 単体シミュレーションで各入力を与えた後、マイルストーンの受入判定を行う前に結果を比較する | 入力・音声受入試験 | 入力・音声受入試験とは、特定ソフトに依存しない入力値とタイマ値を与えてジョイスティックと音声の合否を判定する試験を指す。 |
